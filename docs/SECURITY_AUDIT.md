# Security audit (v2.2, 2026-11-20)

Scope: the whole app (old and new code), its dependencies, the git history and the build. Nullpoint stays a plain
click-through window: no injection, no DirectX hooks, no game memory or game pixels.

## Tools

| Check | Result |
|---|---|
| `pip-audit -r requirements.txt --require-hashes` | No known vulnerabilities |
| `pip-audit -r requirements-dev.txt --require-hashes` | No known vulnerabilities |
| `bandit -r crosshair` (tests excluded) | 0 issues. Before: 2 medium (B310 `urlopen`), 5 low. Fixed or justified below |
| Secret scan of every file version in git history (`detect-secrets` over 414 historical files + regex for GitHub / Twitch / AWS / Discord / private keys) | **No secrets were ever committed.** Hits were only false positives: SHA-256 checksums in the winget manifests, the CS2 code alphabet, a regex, and a dummy token in a test |
| Fuzz tests (`hypothesis`, `crosshair/test_fuzz.py`) | All parsers: random / huge / malformed input only raises the parser's own error, under 1 s, never writes outside its folder |

Bandit `# nosec` lines (each says why in the code): `net.py` B310 (scheme and host checked right above),
`updates.py` / `presence.py` / `main.py` B110 (silent on purpose: offline check, closing a dead connection, old
Windows), `config.py` / `stream_server.py` B105 (empty token placeholders, not passwords), `svg_export.py` B406
(`quoteattr` only escapes our own SVG output, nothing is parsed).

## Dependencies

`requirements.txt` and `requirements-dev.txt` pin exact versions **with hashes** (generated by `pip-compile` from
`requirements.in` / `requirements-dev.in`). `setup.bat` and `build.bat` install with `--require-hashes`, so a
changed or tampered package is refused. Dependabot checks pip and GitHub Actions weekly; CodeQL scans Python and
JavaScript on every push.

## Attack surfaces

| Surface | Finding | Fix / status | Severity |
|---|---|---|---|
| `nullpoint://` handler | A crafted link could add flags (`--safe`, `--autostart`) if it broke out of the quoted `%1` | `parse_args`: when any argument is a link, all flags are ignored; only the link (max 2000 chars) is passed on. Registry entry is HKCU only | Low, fixed |
| Single-instance IPC (`QLocalServer`) | Any local user could connect to the pipe | `UserAccessOption`: only the same Windows user; messages capped at 2000 bytes; only `show` or a validated link is acted on, always with a confirm preview | Low, fixed |
| Share codes (XH1-XH4) | OK: strict key/value parser, ranges clamped, hex checked | Max 2 KB before parsing; fuzzed | Fixed / tested |
| VALORANT / CS2 codes | Length was checked after tokenizing; CS2 had no cap | Length checked first (2000 / 200 chars) | Low, fixed |
| Clipboard watch | Off by default | Only reacts to text that parses as a code; never stores or logs clipboard text; never imports without a click + preview | OK |
| QR decoding | Pasted images had no size check | Clipboard / file images go through `safe_image` (4096 px, 20 MB) before zxing | Low, fixed |
| Dropped files | New in 2.2 | Type by extension, size limits, images through `safe_image`, `.nullpoint` through `packfile.load`, text max 64 KB; always a confirm preview | OK |
| `.nullpoint` files | New in 2.2 | Max 5 MB, schema check, code validated, image decoded with limits, saved under a fresh random name | OK, fuzzed |
| Backup import (`.json` with images) | No size limit; image file names came from the file; a backup could change `update_repo` | Max 50 MB; images validated and stored as `imported_<random>.png/gif/svg` inside `custom\imported`; `update_repo` is never taken from a file | Medium (update source), fixed |
| Zip / library packs | No archive import exists (packs are JSON) | Nothing to slip; noted for future zip support | N/A |
| PNG / GIF / SVG loading | Images from config / library paths were loaded without size checks; network (UNC) paths were opened, which can leak the Windows login hash | All loads go through `safe_image` (Pillow `MAX_IMAGE_PIXELS` set, Qt reader size checked before decoding, GIF max 300 frames, 20 MB); UNC paths refused unless you picked / dropped the file | Medium (UNC), fixed |
| SVG | Could reference external files | Scripts, `foreignObject`, entities and non-local `href`s refused; QtSvg only; max 4096 | Fixed / tested |
| Gallery fetch | `urlopen` with a fixed URL | All HTTP goes through `net.get`: HTTPS only, cert check, host allow-list (github.com, api.github.com, raw/objects.githubusercontent.com), redirects re-checked, 8 s timeout, size limit (1 MB). Entries validated, max 500, names shown as plain text | Low, fixed |
| Stream page | Old page had no token and no Host check | 127.0.0.1 only, random token in the URL, Host header must be 127.0.0.1 / localhost (DNS rebinding), GET only, no CORS, CSP + nosniff, off by default | Medium, fixed in phase 5 |
| Twitch IRC | New in 2.2 | TLS with cert check, token in Windows Credential Manager only, line length limits, exact command only, never echoes chat, cooldown | OK |
| Updater | New in 2.2 | Only after your click: HTTPS GitHub hosts only (`release-assets.githubusercontent.com` added: GitHub's release download host), installer link must be this repo's release, 150 MB limit, fresh private temp folder, SHA-256 checked against the release's `checksums.txt`, file locked against changes and hashed again before it runs, never a downgrade; Authenticode check ready (`REQUIRE_SIGNATURE`) | OK, tested |
| Crash reporter | OK | Local only, user names and home folders scrubbed, no config content | OK |
| Config / library loading | A damaged library used to load as empty (then saved over) | Max 5 MB, schema-normalized, auto-restore from the last 10 backups, broken file kept as `.corrupt`, atomic writes | Fixed in phase 6 |
| Registry writes | OK | HKCU only (Run key, `nullpoint://` handler) | OK |
| Install detection parsers | New in 2.2 | Read-only, 1 MB per file, 500 manifests, type checks, exe names validated | OK |
| Window-title regex rules | Catastrophic backtracking possible | Max 100 chars, nested quantifiers / backreferences / lookarounds refused, titles cut to 256 chars | Fixed / fuzzed |
| DLL loading | Current directory was in the DLL search order | `SetDefaultDllDirectories(LOAD_LIBRARY_SEARCH_DEFAULT_DIRS)` at startup | Low, fixed |
| UI text from outside | Gallery names, tags, authors, file names, codes | Shown with `Qt.PlainText` / escaped; translations checked for markup in tests | OK |
